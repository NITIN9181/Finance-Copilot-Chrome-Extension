# Project Structure

## Overview

This is a Plasmo-based Chrome extension project with a companion demo site. The repository follows Plasmo's conventions for extension development with clear separation between extension components and demo assets.

## Component Organization

### Extension Components

**Background Worker** (`src/background.ts`)
- Handles API authentication and requests
- Manages message passing with content scripts
- No UI rendering

**Content Script** (`src/content.ts`)
- Runs in webpage context
- Detects financial tables on page load
- Extracts and serializes table data
- Injects overlay component

**Popup** (`src/popup.tsx`)
- Standalone UI for extension popup
- API key configuration interface
- Accessed via extension icon in toolbar

**Overlay** (`src/components/copilot-overlay.tsx`)
- Main container injected into host pages
- Tab navigation between features
- Manages overlay visibility and positioning

**Feature Components**
- `flux-analysis.tsx`: Variance cards and top movers
- `chat-interface.tsx`: Chat history and input
- `migration-modal.tsx`: Side-by-side comparison view

### Utility Libraries

**Table Detection** (`src/lib/table-detector.ts`)
- DOM scanning for HTML tables
- Financial table classification logic
- Primary table selection when multiple detected

**Data Extraction** (`src/lib/data-extractor.ts`)
- Parse table structure (headers, rows, cells)
- Currency value parsing and normalization
- JSON serialization of Financial_Dataset

**Variance Calculator** (`src/lib/variance-calculator.ts`)
- Period-over-period percentage change computation
- Top movers identification
- Account type classification (revenue/expense/other)
- Color assignment based on account type and direction

**API Client** (`src/lib/api-client.ts`)
- NVIDIA NIM API request construction
- Streaming response handling
- Error mapping and retry logic

## File Naming Conventions

- **Components**: `kebab-case.tsx` (e.g., `copilot-overlay.tsx`)
- **Utilities**: `kebab-case.ts` (e.g., `table-detector.ts`)
- **Types**: `kebab-case.ts` (e.g., `financial-dataset.ts`)
- **Tests**: `*.test.ts` or `*.spec.ts` (if test suite exists)

## Key Configuration Files

**package.json**
- Dependencies: React, Plasmo, Tailwind CSS
- Scripts: dev, build, package, test
- Plasmo-specific configuration

**tsconfig.json**
- TypeScript compiler options
- Path aliases for clean imports
- Strict type checking enabled

**tailwind.config.js**
- Custom color palette for variance indicators
- Shadow DOM compatibility configuration
- Purge settings for production builds

**manifest.json** (generated by Plasmo)
- Extension metadata and permissions
- Content script injection rules
- Background worker configuration
- Generated from Plasmo conventions + package.json

## Build Artifacts

**Development Build** (`build/chrome-mv3-dev/`)
- Unminified code with source maps
- Hot module replacement enabled
- Verbose error messages

**Production Build** (`build/chrome-mv3-prod/`)
- Minified and optimized code
- No source maps
- Ready for Chrome Web Store submission

## Demo Site Structure

**demo.html**
- Self-contained single file
- Inline styles or Tailwind CDN
- Meridian Supply Co. financial data table
- No external dependencies (except Tailwind CDN)

**vercel.json**
- Routes demo.html as site root
- Static file serving configuration

## Development Workflow

1. **Start Development**: `npm run dev` → Plasmo dev server starts
2. **Load Extension**: Load `build/chrome-mv3-dev` in Chrome
3. **Make Changes**: Edit source files → HMR updates extension
4. **Test on Demo**: Navigate to demo site → Extension auto-activates
5. **Build Production**: `npm run build` → Creates production bundle
6. **Package**: `npm run package` → Creates .zip for Chrome Web Store

## Style Isolation Strategy

- **Shadow DOM**: Overlay components render in shadow root
- **Scoped Styles**: Tailwind classes scoped to shadow DOM
- **No Global Pollution**: Host page styles don't affect overlay
- **No Host Modification**: Overlay styles don't leak to host page

## State Management Locations

- **API Key**: `chrome.storage.local` (persistent)
- **Session State**: React component state (in-memory)
- **Query Quota**: React state in chat-interface.tsx (resets on reload)
- **Financial Dataset**: React state in copilot-overlay.tsx (session-scoped)
